1. CORE FEATURES & OTHER FEATURES
----------------------------------------------------------------

CORE FEATURES (must have):
  - Add a task with a title
  - Set priority: High / Medium / Low (color-coded)
  - Set a due date for each task
  - Mark task as complete / incomplete (checkbox)
  - Delete a task
  - Edit a task title inline (double-click to edit)
  - Filter tasks: All / Active / Done / High / Medium / Low
  - Search tasks by keyword (live search bar)
  - Persist all data in localStorage (survives page refresh)

NEW / CREATIVE FEATURES:
  - Progress bar showing % of tasks completed
  - Overdue indicator: tasks past due date are highlighted in red
  - "Today" badge: tasks due today get a special badge
  - Dark mode toggle (light / dark theme)
  - Confetti animation when ALL tasks are completed
  - Task counter per priority in the header (e.g. 2 High, 1 Low)
  - Sort options: by priority, by due date, by creation date
  - Empty state illustration with motivational message

----------------------------------------------------------------
2. MAIN USER FLOWS (Step-by-Step)
----------------------------------------------------------------

FLOW 1 — Add a Task:
  1. User types task title in the input field
  2. User selects priority from dropdown (default: Medium)
  3. User optionally picks a due date
  4. User clicks "Add" button or presses Enter
  5. Task appears at top of the list with priority badge and due date
  6. Progress bar updates

FLOW 2 — Complete a Task:
  1. User checks the checkbox next to a task
  2. Task text gets strikethrough styling
  3. Task moves to "done" state
  4. Progress bar updates
  5. If all tasks are done → confetti animation plays

FLOW 3 — Edit a Task:
  1. User double-clicks on the task text
  2. Text becomes an editable input field
  3. User types new title
  4. User presses Enter or clicks outside to save
  5. User presses Escape to cancel (reverts to original)

FLOW 4 — Delete a Task:
  1. User clicks the X button on a task
  2. Task is removed immediately
  3. Progress bar updates

FLOW 5 — Search Tasks:
  1. User types in the search bar
  2. List filters live to show only matching tasks
  3. Clearing the search shows all tasks again

FLOW 6 — Toggle Dark Mode:
  1. User clicks the moon/sun icon in the header
  2. App switches between light and dark theme instantly
  3. Preference saved in localStorage

FLOW 7 — Sort Tasks:
  1. User selects a sort option from the sort dropdown
  2. List reorders accordingly without losing any tasks

----------------------------------------------------------------
3. SYSTEM ARCHITECTURE
----------------------------------------------------------------

Type:         Pure Frontend (Single HTML file)
Language:     HTML5, CSS3, Vanilla JavaScript (ES6+)
Storage:      Browser localStorage (no backend, no database)
Deployment:   Static file — open index.html in any browser
              or host on GitHub Pages

Data Model (stored as JSON in localStorage):
  todos = [
    {
      id:        number   (timestamp, unique)
      text:      string   (task title)
      done:      boolean  (completion state)
      priority:  string   ("high" | "medium" | "low")
      dueDate:   string   (ISO date string, optional)
      createdAt: number   (timestamp)
    }
  ]

  settings = {
    darkMode:  boolean
    sortBy:    string ("created" | "priority" | "dueDate")
  }

5. EXCEPTIONS / ERROR STATES & HOW TO HANDLE THEM
----------------------------------------------------------------

  ERROR                         HANDLING
  ─────────────────────────     ─────────────────────────────────
  Empty task title submitted    Show red border on input + shake
                                animation. Do NOT add the task.

  Task title too long (>200)    HTML maxlength prevents typing
                                beyond 200 characters.

  localStorage unavailable      Catch error silently, app works
                                in memory for the session only.
                                Show small warning in footer.

  Invalid/corrupt localStorage  JSON.parse wrapped in try/catch.
                                Reset to empty array if corrupt.

  Due date in the past          Allow it, but flag as overdue
                                with red text and warning icon.

  All tasks deleted             Show empty state with message:
                                "No tasks yet. Add one above!"

  Double-click edit on done     Allow editing, keep done state.
  task

  Very long task text           Text wraps, layout stays intact.
                                No truncation — show full text.
